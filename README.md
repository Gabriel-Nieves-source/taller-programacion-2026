# Programming Workshop 2026

This repository contains the source code and documentation for the Programming Workshop 2026 project. The objective of this repository is to apply software engineering principles, object-oriented programming concepts, version control practices, and collaborative development techniques using Git and GitHub.

The project follows a structured architecture to improve maintainability, scalability, and readability. It is organized according to standard Java project conventions, making it easier for developers to understand and contribute. Throughout the development process, several software engineering practices will be applied, including clean code principles, modular design, code reviews, and continuous improvement.

GitHub Copilot will be used as an AI-assisted programming tool to generate code suggestions, which will then be critically evaluated before being accepted. Every suggestion will be reviewed to ensure correctness, readability, and compliance with project requirements. Version control will be managed through Git using Conventional Commits to maintain a clear and organized project history.

The repository also includes automated build configuration using Gradle, unit testing support, and a standard directory structure for Java applications. Future updates may include additional features, documentation improvements, testing strategies, and architectural enhancements.

This project is intended as an educational exercise to strengthen programming skills, software development methodologies, and professional collaboration practices. It demonstrates the practical use of modern development tools while emphasizing code quality, documentation, and maintainability. Every modification is tracked through Git commits, allowing changes to be reviewed and understood over time. The final result will be a well-organized Java project that reflects good software engineering practices and object-oriented design principles.
